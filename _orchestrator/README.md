# CodeBOT Orchestrator Reference Pack

Paket dokumentasi ini disusun dari arsip orchestrator lama untuk dijadikan acuan saat membangun Orchestrator CodeBOT.

## Isi

- `ORCHESTRATOR-REFERENCE.md`: acuan perilaku, routing lima role, handoff, approval gate, batas eksekusi, skill, status, dan kriteria verifikasi.

## Penting

Ini adalah **paket dokumentasi saja**. Paket ini tidak berisi runtime, profil `.agent.md` yang siap didaftarkan, dynamic workflow siap dijalankan, dependency, credential, log, cache, atau bukti bahwa implementasi CodeBOT sudah lulus.

Tinjau dengan Owner sebelum mengadopsi sebagai instruksi resmi. Semua aksi mutatif dan aksi eksternal tetap tunduk pada approval yang terpisah.
